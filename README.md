# Forex Growth Hub

create a website for a group called LHC Forex that help traders improve their performances on markets and keep being consistent and achieve long term financial growth through personalized coaching , use the link provided below : https://lordrosenagency.netlify.app/.   Layout & Design Requirements:
Bottom-docked / Inline Container:
Floating panel attached above an input field or positioned at the bottom of the chat container.
Background color: use the one on the link provided
Button Grid Structure:
Responsive flex/grid layout supporting dynamic rows.
Multi-column rows where buttons sit side-by-side with equal widths and tight spacing (gap: 6px to 8px).
Standard button height (~40px) with subtle rounded corners (border-radius: 8px to 10px).
Visual Styling:
Native Telegram Aesthetics: Soft translucent slate-, clear white text, medium font weight (14px).
Icons: Support optional emoji or SVG icons aligned left within the button text.  States:
Active/Hover: Slightly lighter background opacity change (#324354).
Ripple Effect: Material Design style ripple or quick opacity drop on click.
Functional Behavior:
Clicking a button should pass its payload/value into the message feed or send a network request without refreshing the page.
Clean, lightweight CSS without heavy external frameworks (or use Tailwind CSS).
